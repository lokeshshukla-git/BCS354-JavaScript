Introduction

This repository contains 15 JavaScript programming lab assignments. These assignments cover basic to advanced JavaScript concepts, including variables, operators, conditions, loops, functions, arrays, objects, classes, DOM manipulation, callbacks, promises and asynchronous programming.

The purpose of these assignments is to understand JavaScript concepts through practical programs and develop basic programming skills.



Assignment 1: Your First JavaScript Script

Aim: To run JavaScript in a browser and with Node.js, and understand variables and data types.

Theory:

JavaScript is a programming language used to make web pages interactive. It can run inside web browsers and with Node.js. Variables are declared using "let" and "const". The "console.log()" method displays output, while the "typeof" operator identifies the data type of a value.

Assignment 2: Operators, Type Conversion and a Calculator

Aim: To understand arithmetic operators, type conversion and conditional statements.

Theory:

JavaScript provides arithmetic operators such as addition, subtraction, multiplication and division. Type conversion changes a value from one data type to another. Conditional statements like "if" and "else if" are used to perform different operations depending on given conditions.

Assignment 3: Conditions and Loops

Aim: To use conditional statements and loops in JavaScript.

Theory:

Conditional statements help a program make decisions based on conditions. The "if", "else if" and "else" statements execute different blocks of code. Loops such as "for" and "while" are used to repeat a block of code until a specified condition is met.

Assignment 4: Writing Functions

Aim: To understand functions, arrow functions and default parameters.

Theory:

Functions are reusable blocks of code that perform specific tasks. They can accept parameters and return values. JavaScript also supports arrow functions, which provide a shorter way to write functions. Default parameters allow a function to use predefined values when an argument is not provided.

Assignment 5: Arrays, Array Methods and Nested Arrays

Aim: To create arrays, access elements and use different array methods.

Theory:

An array is used to store multiple values in a single variable. JavaScript provides methods such as "forEach()" to access each element and "filter()" to create a new array based on a condition. Nested arrays are arrays that contain other arrays and can be used to store data in rows and columns.

Assignment 6: JSON Text

Aim: To convert JavaScript objects into JSON text and JSON text into objects.

Theory:

JSON stands for JavaScript Object Notation. It is a lightweight format used to store and exchange data. JavaScript provides "JSON.stringify()" to convert an object into JSON text and "JSON.parse()" to convert JSON text back into an object. The "try" and "catch" statements help handle invalid JSON data.

Assignment 7: Constructor Functions and Classes

Aim: To create objects using constructor functions and ES6 classes.

Theory:

Constructor functions are used to create multiple objects with similar properties. JavaScript classes provide a structured way to create objects using constructors and methods. The prototype allows methods to be shared by objects created from the same constructor function.

Assignment 8: Inheritance, Methods and Composition

Aim: To understand inheritance, class methods and object composition.

Theory:

Inheritance allows one class to use the properties and methods of another class. JavaScript uses the "extends" keyword to create a child class from a parent class. Composition is a technique in which one object contains another object to combine their functionality.

Assignment 9: DOM, Validation, Storage and Quiz

Aim: To understand DOM manipulation, form validation, local storage and interactive web pages.

Theory:

The Document Object Model (DOM) allows JavaScript to access and modify HTML elements. Events such as button clicks can be used to change page content. Form validation checks user input, while "localStorage" stores data in the browser. JavaScript can also be used to create interactive quizzes.

Assignment 10: Objects and Destructuring

Aim: To create objects, modify their properties and use destructuring.

Theory:

Objects store data in the form of key-value pairs. Their properties can be accessed and modified using JavaScript. Destructuring is a feature that allows values to be extracted easily from arrays and objects and assigned to variables.

Assignment 11: Scope and Closures

Aim: To understand block scope, global scope and closures.

Theory:

Scope determines where a variable can be accessed in a program. Global variables can be accessed from different parts of a program, while block-scoped variables are limited to their block. A closure is created when an inner function remembers and uses variables from its outer function, even after the outer function has finished executing.

Assignment 12: Callbacks and Higher-Order Functions

Aim: To understand callbacks and higher-order functions in JavaScript.

Theory:

A callback is a function passed as an argument to another function and executed when required. A higher-order function is a function that accepts another function as an argument or returns a function. These concepts help make JavaScript programs reusable and flexible.

Assignment 13: Reduce, Some, Every and Map

Aim: To use different array methods and understand how they work.

Theory:

JavaScript provides several useful array methods. The "reduce()" method combines array elements into a single value. The "some()" method checks whether at least one element satisfies a condition, while "every()" checks whether all elements satisfy it. The "map()" method creates a new array by applying a function to every element of the original array.

Assignment 14: Timers and Intervals

Aim: To understand delayed execution, timer cancellation and repeated execution.

Theory:

JavaScript provides timer functions to control when code executes. The "setTimeout()" method executes code after a specified delay, while "clearTimeout()" cancels a scheduled timer. The "setInterval()" method repeatedly executes code after a fixed time interval, and "clearInterval()" stops it.

Assignment 15: Promises and async/await with Local Data

Aim: To understand promises, error handling and asynchronous programming.


Theory:

A Promise represents the eventual success or failure of an asynchronous operation. It can be in pending, fulfilled or rejected states. The "async" and "await" keywords make asynchronous code easier to read and manage. The "try" and "catch" statements are used to handle errors during asynchronous operations.
