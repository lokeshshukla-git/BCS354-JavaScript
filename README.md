# BCS354 – JavaScript Programming Lab

This repository contains 15 JavaScript programming labs completed as part of the BCS354 course. The exercises build practical understanding of JavaScript, from writing a first script to handling asynchronous operations.

## Topics Covered

- JavaScript basics, variables, and data types
- Operators, type conversion, conditions, and loops
- Functions, arrays, and array methods
- Objects, JSON, classes, and inheritance
- DOM interaction, form validation, and browser storage
- Scope, closures, callbacks, and higher-order functions
- Timers, promises, and `async`/`await`

## Repository Structure

Each lab has its own folder (`Lab 1` through `Lab 15`) containing the material for that experiment, such as source files, a lab README, and output screenshots where applicable.

## Tools and Technologies

- JavaScript
- HTML
- Node.js
- Visual Studio Code

## Purpose

The labs provide hands-on practice with core JavaScript concepts and demonstrate how they are used in small programs and browser-based examples.
